Sublanding roadmap

One decision changes the order

Biggest unlock

Build citation tracking first

A product build: API keys and a monthly budget for each engine, a SERP API for AI Overviews, and a scheduler. Then the tracker phases move to the front, and three live overclaims become true.

As planned

Ship everything else first

Phases 0 to 20 need no tracker. The Gemini rank tracker can still ship early as a real free check on the Gemini key already in the project, if you approve the API spend.

No templates: one page, one agent, one directory

These pages roll out in bulk, and Google's spam policies target pages mass-produced from one template. So every page is designed from a blank canvas by its own UI/UX agent and lives in its own folder.
